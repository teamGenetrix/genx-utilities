Read the `readme.md` file within this skill, and explore the other available files (tokens under `tokens/`, components under `components/`, foundation cards under `guidelines/`, full-screen recreations under `ui_kits/`, logos under `assets/`).

**Which skill.** This one covers anything that renders in a browser as an interface. Anything paginated or projected — a proposal, a mission report, a training manual, a letter, a client deck — belongs to `genetrix-docs`, which carries the branded Word and PowerPoint engines, the print stylesheet and the four document plans. Its `references/charte.md` is also the fullest written reference for the brand (verified contrast table, the eleven pillars, the punctuation rules, the official contact block); read it from here whenever a decision goes beyond the key facts below.

If creating visual artifacts (slides, mocks, throwaway prototypes, etc.), copy assets out and create static HTML files for the user to view. If working on production code, copy assets and read the rules here to become an expert in designing with this brand.

Key brand facts: red **#D00000** is a decisive accent (never a large flat fill except the logo block); the palette is otherwise noir/gris/blanc. Type is **Montserrat** in three weights (900 Black affirms, 600 SemiBold structures, 300 SemiLight reads). The signature **red dot `.`** goes at the end of a phrase, used sparingly. Voice is French, direct, precise, numbers-first; no emoji, no em-dash ranges. Base-8 spacing.

If the user invokes this skill without any other guidance, ask them what they want to build or design, ask a few questions, and act as an expert designer who outputs HTML artifacts *or* production code, depending on the need.
