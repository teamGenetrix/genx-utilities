# UI Kit — Genetrix Presentation Template

A 1280×720 slide deck template in the Genetrix brand, click/arrow-key navigable.

**Slide types** (`Slides.jsx`): TitleSlide (noir cover, G watermark), SectionSlide (giant red number), StatSlide (StatFigure trio on noir), ComparisonSlide (Sans cadre / Avec Genetrix, accent-top columns), QuoteSlide (full red testimonial).

Use ← / → or the dots to navigate. Run `index.html`. Needs `../../styles.css`, `../../_ds_bundle.js`, `../../assets/`.
