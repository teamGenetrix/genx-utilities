# UI Kit — Genetrix Marketing Site

Interactive click-through of the Genetrix corporate website, composed from DS primitives.

**Screens / sections** (`Sections.jsx`): sticky Header, noir Hero (headline + stat band), Pillars grid (the 11 leviers as accent-top cards), Offer (Consulting/Training/Coaching Tabs + dark testimonial card), Contact (form → Toast), Footer.

**Interactions** (`App.jsx`): "Prendre rendez-vous" opens a Dialog; submitting the contact form or confirming the dialog fires a success Toast; offer Tabs switch content; nav anchors smooth-scroll.

Run `index.html`. Copy needs `../../styles.css`, `../../_ds_bundle.js`, `../../assets/`.

Copy is representative Genetrix marketing content grounded in the brand's real phrases (potentiel → performance, 11 piliers, +100 organisations, +98% satisfaction); no source website was provided.
